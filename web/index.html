Before you install

This is an early test build. Xebec shows its boot screen and answers this page over USB, nothing more: no sound and no keys yet.

To go back: hold OCT- and OCT+ while switching the FM-1 on. It starts M-VAVE's update loader, and this page can then put M-VAVE's firmware back (below). From there, install your usual firmware from its own page.

Install Xebec

  1. Connect the FM-1 by USB and switch it on, running its current firmware (one with a web installer, like Manta or Tuna).
  2. Use Chrome or Edge, close other MIDI apps, and allow MIDI access when asked.
  3. Press Install and keep this page open until it says done (about two minutes).

Back to M-VAVE's firmware

With the FM-1 in update mode (OCT- and OCT+ held at power-on), choose M-VAVE's stock package FM-1_015.fwsc. It also puts M-VAVE's factory patches back, replacing the ones on the FM-1.
